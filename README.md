## 🌟 Overview / પ્રોજેક્ટ પરિચય

**શ્રી અમદાવાદ ડબગર સમાજ ડિજિટલ પરિવાર પરિચય પુસ્તિકા** એ સમગ્ર ડબગર સમાજના પરિવારો, સભ્યો, વંશાવલી અને સંબંધોને એક તાંતણે જોડતું આધુનિક, ઝડપી અને અત્યંત સુરક્ષિત ડિજિટલ પ્લેટફોર્મ છે. 

આ એપ્લિકેશન દ્વારા સમાજનો પ્રત્યેક પરિવાર પોતાની વિગતો ડિજિટલ સ્વરૂપે નોંધી શકે છે, સંબંધો જોડીને પોતાનું પારિવારિક વંશાવલી વૃક્ષ (Interactive Family Tree) જોઈ શકે છે, સ્વાઇપ સુવિધાવાળું સ્માર્ટ ડિજિટલ ફેમિલી કાર્ડ મેળવી શકે છે, તેમજ સમગ્ર સમાજની પરિચય પુસ્તિકા PDF અને Master Excel શીટ સ્વરૂપે ડાઉનલોડ કરી શકે છે.

## ✨ Key Features / મુખ્ય વિશેષતાઓ

### 1. 📖 ડિજિટલ પરિચય પુસ્તિકા & મલ્ટી-શીટ એક્સપોર્ટ (Directory, PDF, Excel & Print)
- **સંપૂર્ણ પરિચય ડિરેક્ટરી**: સમગ્ર સમાજના પરિવારોની યાદી, મુખ્ય વડીલનું નામ, ગામ/વિસ્તાર અને સભ્યોની સંખ્યા.
- **ઝડપી સ્માર્ટ સર્ચ**: નામ, વ્યવસાય (Occupation), શિક્ષણ (Education), બ્લડ ગ્રૂપ (Blood Group) અને વિસ્તાર (Area) વડે તાત્કાલિક ફિલ્ટર.
- **📄 PDF Export & Direct Print**: સિંગલ પરિવાર તેમજ સમગ્ર પુસ્તિકાનું સુંદર PDF ડાઉનલોડ અને ડાયરેક્ટ A4 પ્રિન્ટ.
- **📊 Native Multi-Sheet Excel (.xlsx) Export**: પરિચય પુસ્તિકા પેજ પરથી ૧ ક્લિકમાં સમગ્ર સમાજનું ૫-શીટ્સ વાળું માસ્ટર એક્સેલ:
  1. *સમાજ પુસ્તિકા* (Directory Overview)
  2. *પરિવારોની યાદી* (All Families)
  3. *હયાત સભ્યો* (Living Members)
  4. *સ્વર્ગસ્થ સભ્યો* (Deceased Ancestors)
  5. *શિક્ષણ અને રોજગાર* (Education & Occupations)
- **🗄️ ઓટોમેટેડ ઈમેઈલ બેકઅપ (`npm run backup`)**: સર્વર પરથી આખો ડેટાબેઝ એક્સેલ શીટ બનાવી એડમિન ઈમેલ પર ઓટોમેટિક મોકલવાની બેકઅપ સ્ક્રિપ્ટ.

---

### 2. 🪪 ડિજિટલ ફેમિલી સ્માર્ટ આઈડી કાર્ડ (Digital Family ID Card with Swipe Flip)
- **સત્તાવાર કમ્યુનિટી ઓળખપત્ર**: પરિવારનો યુનિક ફેમિલી કોડ, હેડનું નામ, સરનામું, બ્લડ ગ્રૂપ અને સભ્યોની યાદી.
- **🔄 સ્વાઇપ ફ્લિપ સુવિધા (Left/Right Swipe)**: મોબાઇલ પર કાર્ડને ડાબે કે જમણે સ્વાઇપ કરવાથી તે તરત જ સ્મૂથ સ્પ્રિંગ-સ્કેલ એનિમેશન સાથે આગળ (Front) અને પાછળ (Back) ફ્લિપ થાય છે.
- **લાઈવ QR કોડ**: કોઈપણ વ્યક્તિ કે સંસ્થા આ QR સ્કેન કરીને ડિરેક્ટરીમાં પરિવારની સત્તાવાર વિગતો ચકાસી શકે છે.
- **PDF & પ્રિન્ટ**: ઓળખપત્રને હાઈ-ક્વોલિટી PDF સ્વરૂપે સાચવી શકાય છે.

---

### 3. 🌳 ઇન્ટરેક્ટિવ ફેમિલી ટ્રી (Hierarchical 3-Generation Family Tree Graph)
- **ઓટોમેટેડ વંશાવલી**: પરિવારના સભ્યો વચ્ચેના સંબંધો (Spouse, Parent-Child) મુજબ ઓટોમેટિક ૩-પેઢીનું વંશાવલી વૃક્ષ.
- **2D Pan અને Smooth Zoom**: ૫૦% થી ૧૮૦% સુધી ઝૂમ ઇન / ઝૂમ આઉટ અને કેનવાસ નેવિગેશન.
- **📸 હાઈ-રિઝોલ્યુશન ઇમેજ એક્સપોર્ટ**: એક જ ક્લિકમાં સમગ્ર વંશાવલી ટ્રી PNG ઇમેજ તરીકે ડાઉનલોડ / શેર કરવાની સુવિધા.
- **સંબંધ લિન્કિંગ મેનેજર**: સભ્યો વચ્ચે પતિ-પત્ની કે પિતા-પુત્રના સંબંધો સરળતાથી મેનેજ કરવા માટેનું ઇન્ટરફેસ.

---

### 4. 🔄 યુનિફાઇડ હેડર રિફ્રેશ & સ્મૂથ પુલ-ટુ-રિફ્રેશ (Unified Header TopBar Refresh)
- **એક સમાન નેવિગેશન હેડર**: એપના તમામ ૫ મુખ્ય ટેબ્સ (`Home`, `Members`, `Booklet`, `Tree`, `Card`) માટે ટોપ હેડરમાં જ સત્તાવાર ૩૬૦° રોટેશન એનિમેશન વાળું રિફ્રેશ બટન.
- **નેટિવ પુલ-ટુ-રિફ્રેશ**: તમામ લિસ્ટ અને કેનવાસમાં નીચે ખેંચીને ડેટા તાજો કરવાની ઉત્કૃષ્ટ મોબાઇલ સુવિધા.

### 5. 🌐 સીધા પબ્લિક વેબ રૂટ્સ (Direct Web Routes for Fast Access)
વેબસાઇટ URL માં સીધા પાથ ખોલવા માટે તૈયાર પબ્લિક રૂટ્સ:
- 🏢 **`/about`**: સમાજનો ઇતિહાસ, ઉદ્દેશ, વિકાસકર્તા પરિચય (Jainish Dabgar), અને સોશિયલ કનેક્ટિવિટી.
- 🔒 **`/privacy`**: સત્તાવાર ડેટા ગોપનીયતા નીતિ અને સિક્યોરિટી નિયમો.
- 📜 **`/terms`**: સત્તાવાર નિયમો, શરતો અને ઉપયોગ નીતિ.
- 📲 **`/download`**: એન્ડ્રોઇડ APK સીધું ડાઉનલોડ કરવા અને આઇફોન (iOS) માટે હોમ સ્ક્રીન શોર્ટકટ ઇન્સ્ટોલ ગાઇડ.

### 6. 💼 વિસ્તૃત વ્યવસાય માહિતી (Structured Dynamic Occupations)
- ૧૨ અલગ-અલગ કેટેગરીઓ (વિદ્યાર્થી, નોકરી, વેપાર, દુકાનદાર, પ્રોફેશનલ, સ્વરોજગાર વગેરે) માટે સ્પષ્ટ ફીલ્ડ્સ.
- **"Other / અન્ય" કેટેગરી માટે ૪ વિશિષ્ટ ફીલ્ડ્સ**:
  1. વ્યવસાયનું નામ (Occupation / Work Name)
  2. પેઢી / કંપની / સંસ્થાનું નામ (Firm / Company / Workplace)
  3. કામનું સ્થળ / શહેર (Work City / Location)
  4. અન્ય વિગત (Additional Details / Notes)
- આ તમામ વિગતો પ્રોફાઈલ, પુસ્તિકા, PDF, Print અને Excel માં સ્પષ્ટ રીતે દર્શાવાય છે.

---

### 7. 🖼️ Cloudinary સિક્યોર ફોટો મેનેજમેન્ટ (Signed Overwrite & Auto-Delete)
- **Signed Overwrite**: Cloudinary API Key અને Secret સાથે સુરક્ષિત SHA-1 સહી વડે સભ્યનો ફોટો સીધો એ જ સ્થાન પર ઓવરરાઈટ થાય છે (ઝીરો ડુપ્લિકેશન).
- **Auto-Delete (Cloudinary Destroy API)**: સભ્યનો ફોટો બદલતાં કે સભ્યને ડિલીટ કરતાં ક્લાઉડિનરી પરથી જૂનો ફોટો આપમેળે કાયમ માટે ડિલીટ થઈ જાય છે.

---

### 8. 🔐 કાયમી લૉગિન & મજબૂત સુરક્ષા (Permanent Session Persistence & Security)
- **WhatsApp/Instagram જેવું કાયમી લૉગિન**: `FileSystem` આધારિત પર્સિસ્ટન્ટ ફાઈલ સ્ટોરેજ (`appStorage.ts`) વડે એપ બેકગ્રાઉન્ડમાંથી સ્વાઈપ કરો કે ફોન રીસ્ટાર્ટ કરો—લૉગિન જળવાઈ રહે છે. માત્ર જાતે "Logout" દબાવવાથી જ લૉગઆઉટ થાય છે.
- **8-Digit Email OTP Password Reset**: ઇમેઇલ પર ૮-અંકનો સત્તાવાર OTP મેળવીને પાસવર્ડ રીસેટ કરવાની સુરક્ષિત પદ્ધતિ.
- **Live Password Strength Indicator**: મજબૂત પાસવર્ડ બનાવવા માટે ૪ નિયમો સાથેનું લાઈવ ઈન્ડિકેટર.
- **⚠️ Danger Zone (Delete Family & Account)**: Google Play Store & Apple App Store ની ગાઇડલાઇન મુજબ ફેમિલી હેડ માટે ડબલ કન્ફર્મેશન (`DELETE`) સાથે કાયમી એકાઉન્ટ અને ડેટા ડિલીટ કરવાનો વિકલ્પ.

## 🚀 Getting Started / શરૂઆત કેવી રીતે કરવી

### Prerequisites / પૂર્વજરૂરિયાતો
- [Node.js](https://nodejs.org/) (v18 અથવા તેથી વધુ)
- [npm](https://www.npmjs.com/) અથવા [yarn](https://yarnpkg.com/)
- [Expo Go App](https://expo.dev/go) (મોબાઈલમાં લાઈવ ટેસ્ટિંગ માટે)

### Database Setup / સુપાબેઝ સેટઅપ

1. [Supabase](https://supabase.com) પર નવો પ્રોજેક્ટ બનાવો.
2. ડેશબોર્ડમાં **SQL Editor** ખોલો.
3. આ પ્રોજેક્ટની `supabase/full_schema.sql` ફાઈલની તમામ સ્ક્રિપ્ટ કોપી કરીને રન કરો.
   *(આ સ્ક્રિપ્ટ તમામ ટેબલ્સ, વિસ્તારો, RLS પોલિસી અને સુરક્ષિત RPC ફંક્શન્સ ૧ ક્લિકમાં સેટઅપ કરી દેશે)*

### Installation / ઇન્સ્ટોલેશન

1. **રિપોઝીટરી ક્લોન કરો:**
   ```bash
   git clone https://github.com/ahmedabaddabgarsamaj/ahmedabad-dabgarsamaj-app.git
   cd ahmedabad-dabgarsamaj-app
   ```

2. **ડિપેન્ડન્સી ઇન્સ્ટોલ કરો:**
   ```bash
   npm install
   ```

3. **Environment Variables સેટઅપ કરો:**
   રૂટ ડિરેક્ટરીમાં `.env` ફાઈલ બનાવો અને તમારા Supabase તેમજ Cloudinary credentials ઉમેરો:
   ```env
   EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here

   # Cloudinary Configuration for Member Profile Photos
   EXPO_PUBLIC_CLOUDINARY_CLOUD_NAME=your-cloudinary-cloud-name
   EXPO_PUBLIC_CLOUDINARY_UPLOAD_PRESET=family_members
   EXPO_PUBLIC_CLOUDINARY_API_KEY=your-cloudinary-api-key
   EXPO_PUBLIC_CLOUDINARY_API_SECRET=your-cloudinary-api-secret

   # Optional: Direct APK download URL
   EXPO_PUBLIC_APK_URL=/ahmedabad-dabgarsamaj.apk
   ```

4. **ડેવલપમેન્ટ સર્વર શરૂ કરો:**
   ```bash
   npx expo start
   ```
   - વેબ પર જોવા માટે કીબોર્ડ પર `w` દબાવો.
   - એન્ડ્રોઇડ ફોનમાં જોવા માટે Expo Go એપથી QR Code સ્કેન કરો.

## 📁 Project Structure / પ્રોજેક્ટ માળખું

```text
├── assets/                  # લોગો, એપ આઈકોન, સ્પલેશ અને ડેવલપર ફોટો
├── public/                  # PWA મેનિફેસ્ટ, સર્વિસ વર્કર, આઈકોન્સ અને APK ફાઈલ
├── src/
│   ├── app/                 # Expo Router સ્ક્રીન્સ
│   │   ├── (auth)/          # લૉગિન, સાઇનઅપ, ફોરગોટ પાસવર્ડ (OTP)
│   │   ├── (family)/        # હોમ, સભ્યો, વંશાવલી, પુસ્તિકા, પ્રોફાઇલ (Danger Zone)
│   │   ├── about.tsx        # સત્તાવાર અબાઉટ પેજ (/about - Public Route)
│   │   ├── walkthrough.tsx  # ૩ સ્ટેપ ઓનબોર્ડિંગ વોકથ્રુ (/walkthrough)
│   │   ├── download.tsx     # Direct APK & iOS PWA Download Page (/download)
│   │   ├── privacy.tsx      # Official Privacy Policy (/privacy)
│   │   ├── terms.tsx        # Official Terms & Conditions (/terms)
│   │   └── +html.tsx        # Web PWA Root, SEO Meta Tags & Early PWA Script
│   ├── components/
│   │   ├── booklet/         # પુસ્તિકા કાર્ડ, સર્ચ અને વિગત મોડલ
│   │   ├── family/          # ડિજિટલ ફેમિલી કાર્ડ અને મુખ્ય ટેબ વ્યુઝ
│   │   ├── navigation/      # ટોપબાર (યુનિફાઇડ રિફ્રેશ, PWA Install બટન) અને બોટમ ટેબબાર
│   │   ├── tree/            # ફેમિલી ટ્રી નોડ્સ અને સભ્ય પ્રોફાઇલ પોપઅપ
│   │   └── ui/              # બટન, ઇનપુટ, બેજ, કન્ફેટી કેનન, સ્કેલેટન
│   ├── constants/           # કલર થીમ, વર્ઝન મેનેજર (version.ts), સંબંધો, શિક્ષણ અને વ્યવસાય લિસ્ટ
│   ├── features/            # Auth, Directory, Family, Members, Tree સર્વિસીસ
│   ├── lib/                 # Supabase ક્લાયન્ટ, Cloudinary Image Service, AppStorage, PDF/Excel યુટિલિટીઝ
│   └── types/               # TypeScript ડેટાબેઝ ટાઇપ્સ
├── supabase/                # ડેટાબેઝ સ્કીમા અને માઈગ્રેશન સ્ક્રિપ્ટ્સ (full_schema.sql)
├── app.json                 # Expo રૂપરેખાંકન (Version 1.0.7)
└── eas.json                 # EAS બિલ્ડ રૂપરેખાંકન
```
